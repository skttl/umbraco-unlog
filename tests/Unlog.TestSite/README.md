# Unlog test site

Umbraco `19.0.0-rc1`, Clean Starter Kit `19.0.0-beta01`, and a project reference to the local Unlog library. Requires the .NET 11 SDK. Both CMS and starter kit are prereleases.

From the repository root:

```sh
dotnet run --project tests/Unlog.TestSite
```

If using the SDK installed locally during the v19 upgrade, run `./artifacts/dotnet/dotnet.exe run --project tests/Unlog.TestSite` on Windows instead.

Open https://localhost:44309/umbraco and complete the installer with a local administrator account and SQLite database. There is no shared administrator password. Clean installs its sample content during site installation. The database, logs, indexes, and media stay local and are ignored by Git. Do not use an existing site's database.

## Test Unlog

Open **Settings > Health Checks > Configuration > Unlog retention**. Confirm the three retention rules and use **Run now**. Check that the result reports the scan and deletion counts, or explains why cleanup was skipped.

`Program.cs` supplies test defaults: Information and lower for 14 days, Warning for 30 days, and all remaining events for 90 days. The recurring job first attempts to run after one minute and repeats hourly. You can override these defaults in the ignored `appsettings.Local.json` while running in Debug.

Today's files are always skipped. To test deletion, use disposable copies of older Umbraco log files in this site's log directory. Never point the test site at production logs. Without older files, a successful run can correctly report zero deletions.

The project reference means rebuilding the site uses the current Unlog source without publishing a NuGet package.

## Package Script Writer

The site was scaffolded using the script generated by [Package Script Writer](https://psw.codeshare.co.uk/), CLI version `1.2.1`:

```sh
psw --template-package 'Umbraco.Templates|19.0.0-rc1' --project-name Unlog.TestSite --starter-kit 'Clean|19.0.0-beta01' --include-prerelease --no-interaction --script-only
```

Its template installation, project creation, and Clean installation commands were run with the .NET 11 SDK. The destination was changed to `tests/Unlog.TestSite`, per-project package management was selected to match this repository, and the Unlog project reference was added. The site's first installation is manual.
